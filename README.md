# Nombre del emprendimiento
Página web desarrollada para [RESTAURANTE EL CASTILLO],
ubicado en [POMPEYA,VILLAVICENCIO,META].
## Problemática de la comunidad
El Restaurante El Castillo necesitaba una herramienta tecnológica que permitiera dar a conocer sus productos y facilitar la comunicación con sus clientes. La página web ayuda a mejorar su presencia digital, mostrar sus empanadas y platos típicos del Llano, e informar a los clientes de manera rápida y sencilla.
