# 🍽️ Restaurante El Castillo

**Desarrollo de una página web para el Restaurante El Castillo**, ubicado en Pompeya, Villavicencio, Meta, Colombia.

## 📌 Descripción del proyecto

Restaurante El Castillo es un proyecto de desarrollo web cuyo objetivo es fortalecer la presencia digital de un emprendimiento gastronómico de la región. La página permite dar a conocer sus productos, destacar sus empanadas y platos típicos de los Llanos Orientales, y facilitar el acceso a información de interés para sus clientes.

El sitio web fue desarrollado utilizando **HTML, CSS y JavaScript**, aplicando conocimientos de programación, diseño web y pruebas de funcionamiento.

## 🎯 Problemática de la comunidad

El Restaurante El Castillo necesitaba una herramienta tecnológica que le permitiera promocionar sus productos y mejorar la comunicación con sus clientes.

La falta de presencia digital puede dificultar que nuevos clientes conozcan los productos y servicios que ofrece el establecimiento. Por esta razón, se desarrolló una página web que contribuye a mejorar su visibilidad en internet, presentar su oferta gastronómica e informar a los usuarios de manera rápida y sencilla.

Con este proyecto se busca apoyar el emprendimiento local mediante el uso de herramientas tecnológicas y promover la gastronomía tradicional de los Llanos Orientales.

## 🛠️ Tecnologías utilizadas

Las siguientes tecnologías fueron utilizadas para el desarrollo del proyecto:

- **HTML5:** estructura y organización del contenido de la página web.
- **CSS3:** diseño visual, estilos y presentación de los elementos.
